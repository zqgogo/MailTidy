# Daily Brief

## When To Use

Use this skill when the user asks for a morning briefing, daily summary, digest,
or quick overview of recent mail.

## Workflow

1. Gather recent unread, starred, actionable, and high-priority emails.
2. Prefer thread summaries over individual message dumps.
3. Highlight decisions, deadlines, blockers, meetings, bills, security alerts,
   and messages from important contacts.
4. Deduplicate newsletters and recurring notifications.
5. Keep optional reading separate from urgent action.

## Evidence

- Include email ids or thread ids for every briefing item.
- Mark whether each item is a direct email fact or an inferred priority.
- Use memory only as context, never as proof that a new message says something.

## Stop Conditions

- Ask the user before expanding into expensive research or reading large threads.
- Do not invent deadlines or commitments if the email text is ambiguous.

## Output

Produce a short briefing that can be read in about two minutes, with sections for
urgent actions, important updates, optional reading, and uncertainties.
